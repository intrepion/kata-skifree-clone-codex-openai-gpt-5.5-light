# Slope Free

A dependency-free browser SkiFree homage. Open `index.html` directly in a browser to play.

## Controls

- `ArrowLeft` / `ArrowRight`: steer
- `Space`: start or restart
- Touch buttons: steer and start/restart on mobile-sized screens

## Gameplay

MVP 1 includes the downhill spine: a full-window snowfield, skier steering, seeded obstacle placement, forgiving collision, a short crash state, and one-key restart.

## Verification

```sh
npm install
npm run check
```
